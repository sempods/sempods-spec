# Retained design material

These non-normative sources remain at their current paths until
[#61](https://github.com/sempods/sempods-spec/issues/61) classifies their content as proposals or
useful maintained guides. [Document ownership](../agents/documentation-strategy.md#document-ownership)
defines those types; new substantial designs use [docs/proposals/](../proposals/README.md).

- [data-access.md](data-access.md) — proposed core for authorized RDF access, optional Context
  contract, implementation examples, requirement impact and mirroring boundaries.
- [access-control.md](access-control.md) — proposed authorization guarantees, delegation,
  revocation, query enforcement and unresolved mutation cases. Its worked ACP design support
  remains under [reference-implementation/](../reference-implementation/README.md).

[#68](https://github.com/sempods/sempods-spec/issues/68) owns normative adoption.
The [source roadmap](../roadmaps/core-data-access.md) retains its bounded authority under the
[transition rule](../agents/documentation-strategy.md#roadmap-transition). Moving or merging these
documents does not change the current normative chapters.
