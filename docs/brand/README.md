# sempods brand assets

This directory is the source of truth for sempods project marks.

The current mark is a **transitional logo**. It uses Google's Material Icons
`Webhook` glyph because the shape matches the project concept well enough for
early open-source use: connected pods, simple geometry, monochrome rendering
and reliable scaling. It should be replaced by an original project logo once
the project has enough adoption to justify professional brand work.

## Canonical files

| File | Use |
|---|---|
| [`sempods-mark.svg`](sempods-mark.svg) | Bare monochrome mark. Use this in headers, docs, social previews and places where the surrounding UI provides size, colour and background. |
| [`sempods-app-icon.svg`](sempods-app-icon.svg) | Square app/org icon with padding and background. Use this for avatars, app launchers and favicon generation. |
| [`sempods-social-preview.png`](sempods-social-preview.png) | The card a shared repository link renders as. Raster because GitHub's social preview is, and uploaded per repository through Settings → General — it has no API. |
| [`source/material-webhook.svg`](source/material-webhook.svg) | Upstream-derived source glyph kept for attribution and review. Do not edit this file for product use. |

## Redrawing the social preview

There is no script. When the mark is replaced, whoever draws it has a design tool open and the
card comes out of that — a program here to reproduce one layout would be a dependency this
repository maintains for a job it does once. What is worth keeping are the measurements, so the
replacement lands in the same shape:

| | |
|---|---|
| Canvas | 1280 × 640, the size GitHub recommends; it crops smaller in some surfaces, so nothing important goes near an edge |
| Mark | 288 × 288, top-left corner at (496, 116) — centred horizontally, sitting above the words |
| Type | Helvetica, falling back to Arial then any sans-serif. Both lines centred on x=640 |
| Wordmark | `sempods`, 62px, baseline at y=486, letter-spacing 1 |
| Tagline | `your data belongs to you`, 25px, baseline at y=532, no extra tracking |
| Colours | `#111111` ground, `#ffffff` mark and wordmark, `#9a9a9a` tagline — the app icon's palette |

The tagline is the website's first line. If that changes, this follows rather than becoming a
second one.

Consumer repositories should copy from this directory, not from Material UI,
Google Fonts or an already-generated downstream asset. If a consumer needs
PNG, ICO or Apple touch icon files, generate them from `sempods-app-icon.svg`
inside that consumer repository.

The sempods wrapper files in this directory change the exported SVG structure,
accessible labels, colour handling, padding and app-icon background. The glyph
shape itself is intentionally left unchanged for this transitional version.

Keep the repository-level `NOTICE` entry when distributing these files.

## Replacement criteria

A future original logo should meet at least these constraints:

* works as a one-colour SVG;
* stays legible at 16, 24 and 32 px;
* does not depend on gradients, shadows or raster effects;
* has enough visual distance from Material Icons and other common icon sets;
* can be used as both an organisation mark and a website/app logo.
