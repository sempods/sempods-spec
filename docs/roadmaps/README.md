# Retained roadmaps

These are the two unmigrated source roadmaps governed by the
[roadmap transition](../agents/documentation-strategy.md#roadmap-transition). That rule owns their
temporary authority, progress updates and retirement boundary. New work uses
[Issue planning](../agents/documentation-strategy.md#issue-planning).

- [core-data-access.md](core-data-access.md) — proposed core adoption, validation and downstream
  handoff. [#68](https://github.com/sempods/sempods-spec/issues/68) owns the destination adoption path.
- [spec-0.1.md](spec-0.1.md) — the first specification release and its open decisions, which remain
  the [release gate](../../GOVERNANCE.md#what-has-to-be-settled-first) until the ownership switch.

[#62](https://github.com/sempods/sempods-spec/issues/62) verifies the issue mapping and retires
these sources and the [retained procedure](../agents/roadmap-lifecycle.md) together. Keep completed
work and decisions available until that switch; a file's retirement does not establish adoption or
satisfy its release conditions.
